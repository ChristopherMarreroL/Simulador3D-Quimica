# Vinagre y bicarbonato: modelo del prototipo

Ecuación balanceada:

**NaHCO₃ + CH₃COOH → CH₃COONa + H₂O + CO₂**

Se usa una disolución educativa definida de ácido acético a **0,83 mol/L**; no se interpreta una etiqueta de vinagre comercial como molaridad. Volumen seleccionable: 1–150 mL. Masa de bicarbonato: 0,01–10 g. Vaso nominal de 250 mL, abierto.

- n(ácido) = 0,83 mol/L × V(mL) / 1000.
- n(bicarbonato) = m(g) / 84,0066 g/mol.
- Por la relación 1:1, n(CO₂) = min(n(ácido), n(bicarbonato)).
- Los moles remanentes se calculan restando la extensión de reacción a cada reactivo.
- V(CO₂) = nRT/P, R = 0,082057 L·atm·mol⁻¹·K⁻¹; T = 298,15 K y P = 1 atm.

Ejemplo: 50 mL y 5 g producen teóricamente 0,0415 mol de CO₂; limita el ácido. Volumen ideal aproximado: 1,015 L. El gas escapa; este volumen no equivale al volumen de líquido ni de espuma dentro del vaso.

Supuestos: reactivos puros en las cantidades indicadas, mezcla homogénea, conversión estequiométrica completa. No se calcula equilibrio ácido/base, pH, CO₂ disuelto, vapor de agua, temperatura variable ni velocidades experimentales. La intensidad y duración de burbujas dependen de los moles teóricos mediante una función visual determinista. El modelo visual no constituye una ley cinética ni una medida de espuma. Se reinicia la estación entre ensayos; no se permiten adiciones sucesivas a una mezcla ya reaccionada.
